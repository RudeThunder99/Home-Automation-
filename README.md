# Home-Automation-
This project automats many household appliances to ensure safety,efficiency,and maximum energy saving. I am using multiple ESP32 boards to create a network of IoT devices that serves many purposes like energy saving, home security, fire safety, and many more. The whole system activates with the sound of a clap. There is a main ESP32 that acts as a hub and receives data from the other ESP32 boards via Wi-Fi. The other ESP32 boards are working on different subsystems like water plant monitoring, fire hazards, smoke or gas leakage, weather monitoring (humidity, temperature and rain status), Intruder detection etc. It is to be noted that this project can be expanded greatly, depending on how many new purposes can be given for the system to serve. 

## Why I made this project: 
I have always wanted to make a home automation system of my own but the actual reason that got me started working on this project is a science fair at my school. This development of this project was for both my personal interest and as a science fair project. I want to bring the home automation ideas that are in my head to the real world and solve real-life problems. Although the devices I have made here may already exist, I tried to add some unique details. This is my first ever working on a home automation system and I hope I will invent some new unique systems that serve the purpose of automating our smart homes even more.
